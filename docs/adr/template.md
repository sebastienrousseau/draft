# NNNN. Title in the imperative

- **Status:** Proposed | Accepted | Superseded by a later record
- **Date:** YYYY-MM-DD

## Context

What was true when this was decided. Forces, constraints, and what was
actually measured rather than assumed.

## Decision

What was chosen, stated in one or two sentences.

## Alternatives considered

Each with the reason it lost. An alternative with no stated reason reads as one
that was never really considered.

## Consequences

What this costs, not only what it buys. If there is no cost, the decision was
not a decision.
